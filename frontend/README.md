# Frontend

SvelteKit storefront for Ceynic. Requires Node 22.

From this directory, run `npm ci`, then `npm run dev` for local development, `npm run check` for type checking, and `npm run build` for a production build. Set `PUBLIC_API_URL` in `frontend/.env` to the backend URL; `.env` and `.env.development` are ignored by Git.

The JSON schemas in `src/lib/schemas` and TypeScript interfaces in `src/lib/interfaces` are generated by `uv run ceynic generate-frontend-models` from `backend/` after both applications have been installed.

See the [monorepo README](../README.md) for the branch and deployment flow.
